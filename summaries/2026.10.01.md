
## `microsoft/SkillOpt`

> SkillOpt is a text-space optimizer that trains reusable natural-language skills for frozen LLM agents through trajectory-driven edits, validation-gated updates, and deployable best_skill.md artifacts.

[URL](https://github.com/microsoft/SkillOpt) / [Homepage](https://aka.ms/skillopt) / 言語: Python

SkillOpt は text-space optimizer で、凍結された LLM エージェント向けに再利用可能な自然言語スキルを学習させるフレームワークです。軌跡駆動の編集 (trajectory-driven edits)、検証ゲート付きの更新 (validation-gated updates)、およびデプロイ可能な best_skill.md アーティファクトの生成を通じて、モデルの重みを変更せずにエポック、(ミニ)バッチサイズ、学習率といった学習的概念でスキルを洗練します。Python 3.10+ 対応、PyPI パッケージ化、MIT ライセンスで公開されており、自己進化するエージェントスキルの研究や実運用に使えるツールキットを提供します。

[URL](https://github.com/cloudflare/security-audit-skill) / 言語: JavaScript
